# Criterios de Validación: Fase 4 - Pulido Final

La Fase 4 se considerará lista para dar por cerrado el proyecto cuando se cumplan los siguientes puntos:

## Interfaz y Usabilidad
1. [ ] **Toasts Funcionales:** Ingresar un PIN incorrecto no rompe la interfaz, sino que muestra una notificación temporal indicando el fallo en la esquina de la pantalla.
2. [ ] **Retroalimentación Visual:** El portapapeles y todas las transferencias exitosas muestran notificaciones que confirman al usuario que la acción se completó.
3. [ ] **Estilo Consistente:** La apariencia global de los controles UI respeta los colores primarios y las formas dictadas en los design tokens definidos en el sistema de marca.

## Ejecución Global
1. [ ] **Arranque Simplificado:** Un usuario puede descargar el repositorio y ejecutar el script `start` en la raíz; con esto se inician ambos servidores sin que el usuario deba correr comandos por separado.
2. [ ] **Documentación Completa:** El `README.md` explica claramente el propósito del proyecto y el comando de arranque para un nuevo usuario.
